# The app icon

`OrbitTrap-icon.m3s` is the icon's scene, made for this app: a loxodrome
(loxodromeIFS, the spiral course that keeps one compass bearing around a
globe), gold on a dark blue background, seen at an angle. Render it with

    mb3d ios/icon/OrbitTrap-icon.m3s --aa 2 -o AppIcon-1024.png

and save it, without transparency, as
`App/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`.
